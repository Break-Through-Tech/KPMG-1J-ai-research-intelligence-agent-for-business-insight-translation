**Research Objective**  
Investigate how long‑context language models can lower memory bandwidth and compute costs during inference, specifically by quantizing the recurrent state used in linear‑attention (hybrid) architectures while preserving model quality. [2609.38166v1]

**Methodology**  
The authors introduce **LeapQuant**, a training‑free quantization technique for the recurrent state of linear‑attention models. It comprises two main components:  

1. **Per‑window quantization** – the state is kept in low‑precision only at window boundaries; within a window, updates are buffered in higher precision and the state is reconstructed and quantized once at the end of the window. [2609.38166v1]  
2. **Compensator Tokens** – the largest outlier rows/columns of the state are stored as a few high‑precision rank‑one tokens that share the normal token‑update path, and the remaining residual is smoothed before quantization. [2609.38166v1]  

The method requires no model retraining or calibration data. Experiments evaluate LeapQuant on the Qwen, Kimi, and GLM model families (12 model–task pairs) across NVIDIA B200, RTX PRO 6000, and RTX 5090 GPUs, measuring accuracy, memory traffic, memory footprint, and inference speed at both kernel and end‑to‑end levels. [2609.38166v1]

**Key Findings**  
- LeapQuant attains **near‑lossless accuracy** under 8‑bit recurrent‑state quantization, matching the FP32 baseline. [2609.38166v1]  
- **Per‑window quantization** dramatically reduces error accumulation: error at 64 K tokens is 100× lower for BF16 and 39× lower for INT8 compared with per‑step quantization. [2609.38166v1]  
- **Compensator Tokens** effectively handle outliers, further lowering quantization error. [2609.38166v1]  
- Memory and compute savings: state memory traffic is reduced by **3.4×**, end‑to‑end memory footprint shrinks by up to **56%**, and inference speed improves by **2.05–3.70×** at the kernel level and **1.47×** overall. [2609.38166v1]
