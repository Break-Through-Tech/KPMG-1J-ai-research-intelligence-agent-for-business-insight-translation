**Research Objective**  
Investigate how the choice of simulated user (user proxy) influences benchmark outcomes for interactive AI agents, and assess whether user‑side fidelity is captured by standard task‑reward metrics. [2609.38043v1]

**Methodology**  
- Introduced **UserProxyBench**, an evaluation layer over the τ‑bench family that scores the user proxy independently of the agent. [2609.38043v1]  
- Defined the **User Fidelity Score (UFS)** as the fraction of episodes in which the proxy satisfies every contract‑specified criterion derived from a private user blueprint, simulator guidelines, and task‑specific rubrics (2,141 criteria total across four domains). [2609.38043v1]  
- Evaluated **seven user proxies** (three open‑weight, four hosted models) on the full base split of **375 enterprise tasks** (Telecom 114, Airline 50, Retail 114, Banking 97). The agent was frozen as **GPT‑5.5**; only the user proxy varied. [2609.38043v1]  
- For each proxy‑task pair a single rollout was collected, yielding 2,618 scored trajectories (after discarding a few error cases). [2609.38043v1]  
- Measured both the standard benchmark **task reward (Rτ)** and the **UFS**, and recorded user‑side inference cost (token‑based pricing for self‑hosted models or billed spend for hosted models). [2609.38043v1]  

**Key Findings**  
- Changing only the user proxy while keeping the agent fixed altered the **mean task reward by 15.2 points** across the 375 tasks. [2609.38043v1]  
- **24.4 % of successful episodes** violated the user contract; in the Telecom domain this rose to **39.7 %** of all trajectories (reward pass / UFS fail). [2609.38043v1]  
- The most common failure was **premature disclosure** (information given before the agent asked), occurring in **480** episodes. This failure had minimal impact on reward (average change in agent pass rate ≈ ‑0.043) but reduced the number of tool calls by **1.06 per successful episode**. [2609.38043v1]  
- Task reward **Rτ** did not capture user fidelity: mean Rτ values ranged from **0.644 to 0.796** across proxies, with per‑domain spreads of **0.132–0.298** (e.g., 0.280 on Airline, 0.298 on Retail). [2609.38043v1]  
- An empirical **cost–fidelity frontier** was identified. For a required fidelity **q = 0.84**, **Gemma‑31B** is the cheapest qualifying proxy (UFS = 0.845, ≈ $0.0175 per simulation). Higher fidelity (q = 0.86) shifts the optimal choice to **Gemma‑31B**, while lower fidelity (q = 0.75) favors **GPT‑4.1‑mini**. Some proxies are strictly dominated (cheaper and more faithful alternatives exist). [2609.38043v1]  

**Limitations**  
- The rubric generation and grading both rely on the same model (**Claude Opus 4.8**), which the authors note as a limitation (potential bias in rubric creation and scoring). [2609.38043v1]  
- Only a single rollout per proxy‑task pair was collected, limiting assessment of variability across runs. [2609.38043v1]  
- The study is confined to the τ‑bench family of enterprise tasks (Telecom, Airline, Retail, Banking) and may not generalize to other domains or to human‑in‑the‑loop evaluations. [2609.38043v1]
