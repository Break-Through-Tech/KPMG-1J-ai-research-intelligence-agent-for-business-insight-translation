**Research Objective:**  
Investigate techniques for lowering the memory‑bandwidth and compute overhead of long‑context language models that use linear‑attention‑based recurrent states, while preserving model quality. The work targets hybrid LLM designs (e.g., Gated DeltaNet, Kimi Delta Attention) whose recurrent state updates dominate inference cost. [2609.38166v1]

**Methodology:**  
1. Analyze the inference bottleneck of recurrent‑state access in linear‑attention layers, showing that per‑token read/write of the full state exhausts HBM bandwidth and inflates GPU memory usage (especially with prefix caching). [2609.38166v1]  
2. Propose **LeapQuant**, a training‑free quantization scheme that (a) performs **per‑window quantization**—the state is kept in low‑precision only at window boundaries, while high‑precision token updates are buffered and applied later; (b) introduces a small set of high‑precision **Compensator Tokens** that capture the largest outlier rows/columns of the state, leaving a smoother residual for quantization. Both steps require no calibration data. [2609.38166v1]  
3. Implement the method on several recent hybrid model families (Qwen, Kimi, GLM) and evaluate on a range of GPUs (NVIDIA B200, RTX PRO 6000, RTX 5090). Metrics include kernel‑level throughput, end‑to‑end inference speed, memory‑traffic reduction, and accuracy relative to an FP32 baseline. [2609.38166v1]

**Key Findings:**  
- LeapQuant attains **near‑lossless accuracy** under 8‑bit recurrent‑state quantization, matching the FP32 baseline across 12 model‑task pairs. [2609.38166v1]  
- Per‑window quantization dramatically curtails error accumulation: quantizing once per 16‑token window reduces state‑MSE at 64 K tokens by **≈100×** for BF16 and **≈39×** for INT8 compared with naïve per‑token quantization. [2609.38166v1]  
- Adding Compensator Tokens further lowers quantization error, keeping the overall error below that of per‑window BF16 even with fewer bits. [2609.38166v1]  
- Memory and compute savings: state‑memory traffic drops by **3.4×**, and the end‑to‑end memory footprint shrinks by up to **56 %**. [2609.38166v1]  
- Performance gains: kernel‑level speedups of **2.05–3.70×** and end‑to‑end inference speedup of **1.47×** on the tested GPUs. [2609.38166v1]
