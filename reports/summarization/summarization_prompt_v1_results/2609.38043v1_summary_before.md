**Research Objective:**  
Assess how the choice of simulated‑user proxy influences interactive‑agent benchmark outcomes and introduce a metric (User Fidelity Score, UFS) to measure whether a user proxy faithfully follows the benchmark’s private user specifications (functional fidelity). [2609.38043v1]

**Methodology:**  
- Built **UserProxyBench**, an evaluation layer on top of the τ‑bench family that scores the user side independently of the agent. [2609.38043v1]  
- Defined **UFS** as the fraction of episodes in which the proxy satisfies every contract criterion derived from a private user blueprint, simulator guidelines, and task‑specific instructions. Rubrics (2 141 criteria across four domains) were authored by Claude Opus 4.8 and independently verified by a separate model (GPT‑5.6‑Sol). [2609.38043v1]  
- Evaluated **seven** reported user proxies (three open‑weight, four hosted) on the full base split of **375** enterprise tasks (Telecom, Airline, Retail, Banking) while keeping the agent fixed at **GPT‑5.5**. Each task received a single rollout per proxy. [2609.38043v1]  
- Recorded the benchmark’s agent‑side task reward (**Rτ**) and the user‑side inference cost (token‑based pricing or billed spend). Analyzed the cost‑fidelity trade‑off and identified an empirical cost–fidelity frontier. [2609.38043v1]

**Key Findings:**  
- Changing only the user proxy while holding the agent constant altered the **mean task reward by 15.2 points** (≈ 0.152 on a 0–1 scale). [2609.38043v1]  
- Across all 2 618 scored trajectories, **24.4 % of agent‑successful episodes violated the user contract**; in Telecom, 39.7 % of trajectories were reward‑pass / UFS‑fail. [2609.38043v1]  
- The most frequent violation was **premature disclosure** (information given before the agent asked), occurring in 480 episodes. This failure had a negligible impact on reward (average pass‑rate change − 0.043) but reduced the number of tool calls by **1.06 per successful episode**. [2609.38043v1]  
- Mean **Rτ** values for the frozen GPT‑5.5 agent ranged from **0.644 to 0.796** across proxies; per‑domain spreads reached up to **0.298** (Retail). [2609.38043v1]  
- **Cost‑fidelity frontier:** at a required UFS of 0.84, **Gemma‑31B** is the cheapest qualifying proxy (UFS 0.845, ≈ $0.0175 per simulation). Higher fidelity (UFS 0.86) shifts the optimal point to **Gemma‑3.5‑Flash**, which costs 3.2 × more. Some proxies are strictly dominated (cheaper and more faithful alternatives exist). [2609.38043v1]  
- Removing disclosure criteria from the scoring dramatically reshuffles proxy rankings (e.g., Qwen3.6‑35B moves from sixth to third), showing that **UFS captures failure modes invisible to reward‑only metrics**. [2609.38043v1]

**Limitations:**  
- The rubric‑generation and grading steps both use the same model (Claude Opus 4.8), which may introduce bias; the authors note this as a limitation to be addressed later. [2609.38043v1]  
- Evaluation used a single rollout per proxy per task (no repeated trials) and covered only **375** enterprise tasks, potentially limiting statistical robustness. [2609.38043v1]  
- The study fixes the agent to **GPT‑5.5**, so findings may not generalize to other agents or to multi‑agent settings. [2609.38043v1]  
- Five trajectories were unscorable because no applicable criterion existed, indicating that the rubric coverage is not universal. [2609.38043v1]  
- UFS measures **contract adherence** rather than human‑likeness; it does not assess how realistic the simulated user is compared to real users. [2609.38043v1]
